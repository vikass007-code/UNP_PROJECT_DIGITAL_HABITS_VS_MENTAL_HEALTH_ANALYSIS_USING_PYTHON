# UNP_PROJECT_DIGITAL_HABITS_VS_MENTAL_HEALTH_ANALYSIS_USING_PYTHON


Digital Habits vs Mental Health – Regression Analysis

A machine learning regression project that analyzes the relationship between digital habits, sleep, mood, and mental health. The project uses a dataset of 100,000 records and examines factors such as screen time, social-media usage, TikTok usage, and sleep hours to predict stress levels.

The project includes data preprocessing, exploratory data analysis, correlation analysis, and regression modeling. Four models—Linear Regression, Decision Tree, Random Forest, and KNN—were compared based on R², MAE, and RMSE. Linear Regression achieved the best performance with an R² of 0.744 using a 60:40 train-test split.

The analysis found that sleep had the strongest relationship with stress, while higher screen time was associated with higher stress levels. The project provides data-driven insights into digital habits and wellbeing while emphasizing that the results show association, not causation.

Tools & Concepts: Python, Pandas, Data Preprocessing, EDA, Data Visualization, Correlation Analysis, Machine Learning, Regression & Model Evaluation.
